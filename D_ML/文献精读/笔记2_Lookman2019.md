# 📝 笔记二：Active learning in materials science

**基本信息**
- 标题：Active learning in materials science with emphasis on adaptive sampling using uncertainties for targeted design（材料科学中的主动学习：以不确定性驱动的自适应采样实现定向设计）
- 作者 / 机构：Turab Lookman（洛斯阿拉莫斯国家实验室）、Prasanna V. Balachandran（弗吉尼亚大学）、Dezhen Xue、Ruihao Yuan（西安交通大学）
- 期刊 / 年份 / 卷期 / 页码：*npj Comput. Mater.* **2019**, *5*, 21
- DOI：10.1038/s41524-019-0153-8（综述 Review）

**1. 这篇解决什么问题？（背景与动机）**
材料搜索空间动辄上百万个候选，trial-and-error 不现实。而常见的"先攒大数据→训模型→预测"路线也有问题：**预测≠最优决策**——它没有不确定性估计，也很少有例子能超过训练集里已知的最好材料。缺的环节是：**怎么用模型决定"下一个该测谁"**。

**2. 核心方法：主动学习闭环（画出流程）**
```
预测 → 决策 → 验证 → 更新 →（循环）
```
① **预测**：用代理模型（GPR/SVR/RF）在未测点上给出预测值 μ 和不确定性 σ；② **决策**：用采集函数（utility function，如 E[I]）给所有候选打分，选 argmax 的那个做下一次实验/模拟；③ **验证**：做实验或跑计算，拿到真实值；④ **更新**：新数据加进训练集，重新训练模型，回到①。直到目标达成（图 2 就是我们的 W7–W9 pipeline）。

**3. 关键概念（用自己的话解释）**
- **代理模型（surrogate model）**：用少量训练点拟合的"便宜替身"（GP 等），代替昂贵的真实验证（DFT、P-S 求解器、真实实验）。
- **采集函数 / utility function**：给"下一个测谁"打分的函数。三种：E[I]（无噪声假设）、Knowledge Gradient（有噪声）、MOCU（面向目标的贝叶斯不确定性）。
- **期望改进 E[I]**：`E[I(x)] = (μ−f(x⁺))·Φ(...) + σ·φ(...)`。**μ 管"利用"**（选预测值高、可能超过当前最优 f(x⁺) 的地方），**σ 管"探索"**（选不确定性大、信息量大的地方）；两者都大的点最值得采样。两种极限：σ 小→纯利用（E[I]→μ−f(x⁺)），σ 大→纯探索（E[I]→σ）。
- **探索 vs 利用**：多臂老虎机问题。纯利用容易陷进局部最优，纯探索浪费昂贵实验，E[I] 自动权衡二者。
- **停止判据的教训**：maxE[I] 并不单调下降——例 3 里最优材料第 9 轮就找到了，但 maxE[I] 到第 16 轮才归零。**不要一看到 E[I] 变小就停，要确认它持续不回升**（或按预算/目标值停）。

**4. 三个应用例子（各用一句话总结）**
- **例 1 铁电材料（实验）**：约 60.5 万种 (Ba,Ca,Sr)(Ti,Zr,Sn)O₃ 组成中只合成了 61 个训练点（0.01%），用 SVR + bootstrap 1000 模型估不确定性，E[I] 策略每轮都最优，第 3 轮就找到最大电致应变的组成，随机采样最差（20 个新样品中 9 个超过训练集最优，Fisher p<0.001）。
- **例 2 LED 模拟（代理模型）**：用 GP 代理 APSYS 的 Poisson–Schrödinger 求解器，E[I] 选点，25 次迭代就达到最优效率的 75%，150 次后 R²>0.99。
- **例 3 DFT 磷灰石（计算引导）**：96 种 A₁₀(BO₄)₆X₂ 组成、仅 13 个训练点、100 个 SVR-RBF 集成，第 9 次迭代找到最大带隙的 Ca₁₀(PO₄)₆F₂（Eg=5.67 eV），25 次迭代预算只用了 9 次。

**5. 对我们项目的启示（最重要！）**
- **直接照搬**：GPR 代理模型 + E[I] 采集函数 + 结果回流重训 = 我们 W7–W9 的主动学习主循环；超参数用最小化负对数边际似然（**就是周一学的 LML**）；不确定性可以用集成/bootstrap 估（例 1 做法）。
- **跟我们最像的场景是例 3**（计算代码当"实验"）和例 1（每轮实验贵）——区别是我们的"搜索空间"是**序列空间**（不是组分），特征要自己定义（W2 任务）。
- **要改的**：我们的单轮模拟成本高，收敛判据更要谨慎——参考本文：连续几轮 maxE[I] 都≈0 再停（对应我们 W8 的"连续两轮提升<5%"）。
- **模型糙也能跑**：作者实证"主动学习对模型质量宽容"（模型不准时 E[I] 仍优于随机）→ 不要等模型完美了再开闭环，先转起来。

**6. 疑问 / 想讨论的点**
- E[I] 假设观测噪声 y=f+ε 且 ε 正态——我们模拟 κ 的误差（有限体系、统计涨落）怎么估计？是否对应 GPR 的 alpha 参数？（这正好和 W4 数据规范里要留 kappa_err 列呼应。）
- 例 1 用 bootstrap 集成估 σ，我们打算直接用 GPR 自带的后验方差——两者差别大吗？要不要 W5 做个小对比？

## 附：例会一句话版本
- **主动学习用"预测+不确定性"挑下一个实验/模拟，60 万个候选只用 61 个样本就能定向找到最优——我们用 20 次模拟找高导热序列，靠的就是这个闭环。**

## 桥梁（与文献①）
文献①说"高分子数据贵、难建"，文献②说"主动学习能用极少数据高效设计材料"——合起来就是本项目立项逻辑：**模拟慢（数据贵）→ 用不确定性驱动采样 → 用最少的模拟次数找到高导热序列**。Audus 文中引用的 Mannodi-Kanakkithodi 2016（聚合物电介质设计）正是 Lookman 合作组的工作，两篇属于同一条学术脉络。
