## 文献①：Polymer Informatics: Opportunities and Challenges（高分子信息学：机遇与挑战）

**基本信息**
- Audus, D. J.; de Pablo, J. J. *ACS Macro Lett.* **2017**, *6*, 1078–1082. DOI: 10.1021/acsmacrolett.7b00228
- 类型：Viewpoint（观点文章，短，正文只有 5–6 页，适合精读全文）
- 作者背景：Audus（NIST）、de Pablo（芝加哥大学分子工程研究所）——高分子信息学领域奠基人

**一句话总结**
材料信息学（第四范式）在金属/氧化物上已经成功，但要用在聚合物上，最大瓶颈不是算法而是**数据：聚合物怎么描述、性质怎么定义、上下文怎么记录**。

**正文结构与重点段落导航**（PDF 页码）
| 页码 | 内容 | 重点 |
|---|---|---|
| p1–2 | 摘要 + 材料发现框架 | ⭐ 图 1：材料发现五步框架 (1) 需求规格 → (2) 信息学+模拟预测候选 → (3) 实验验证 → (4) 工厂 → (5) 产品；"第四范式"概念 |
| p3 | 已有案例 | 无机材料 ML 成功；聚合物只有零星预测（玻璃化温度、介电常数…），**用于"设计"而非"预测"的极少** |
| p4 | 最大障碍 | ⭐ **"最拦路的是数据库缺失，不是算法缺失"**——这是全文核心论点；文献量翻倍 vs 人工提取不可持续 → 自动化建库（Watson、ChemDataExtractor） |
| p5 | 挑战一：聚合物不是单一实体 | 分子量分布、分散度；聚苯乙烯有 1800+ 种叫法；命名问题（IUPAC/CAS 不足 → PolyInfo 自建编号 → InChI 部分解决） |
| p6 | 挑战二：性质的定义 | 性质分三类：**基础性**（密度/黏度，无需额外信息）、**应用性**（需指定测量方法，如 ASTM 标准）、**现象学**（无严格物理意义，如 Flory–Huggins χ 参数） |
| p7 | 挑战三：上下文信息 | 连"密度"这种基础性质都受加工历史影响；误差棒、数据真实性、"未报告结果"（non-reporting）问题 |
| p8–9 | 作者的实践 | 他们建 χ 参数数据库（PPP 数据库）：自动化 + 众包结合；数据沉淀三形式（文章附链接 / 存库有持久 ID / 直接入统一 schema 数据库，类比 RCSB 蛋白库） |
| p10 | 结论 | 聚合物是 5000 亿美元产业，机会巨大，但必须先解决"如何描述材料、解释性质、记录上下文、共享数据" |

**读的时候重点想（笔记必答）**
1. 为什么作者说"数据库缺失比算法缺失更致命"？
2. 我们项目的数据管线设计（W6 统一 CSV/JSON 格式）如何回应这篇的担忧？
3. χ 参数属于哪类性质？为什么它很难进数据库？（联系你学的 GPR：phenomenological 性质的数据噪声大 → 对 ML 意味着什么？）

## 文献②：Active learning in materials science（材料科学中的主动学习）

**基本信息**
- Lookman, T.; Balachandran, P. V.; Xue, D.; Yuan, R. *npj Comput. Mater.* **2019**, *5*, 21. DOI: 10.1038/s41524-019-0153-8
- 类型：Review Article（综述，17 页；**我们项目的 M3/M4 理论核心**）

**一句话总结**
用"代理模型（如 GPR）的预测 + 不确定性"驱动一个迭代闭环：每轮用**采集函数**（utility function）挑出下一个最值得做实验/模拟的候选，而不是盲目穷举。

**正文结构与重点段落导航**
| 页码 | 内容 | 重点 |
|---|---|---|
| p1–2 | 引言：加速材料发现 | ⭐ 核心问题："怎么引导实验走向目标性质？"；传统 trial-and-error 不可行；ML 预测本身**不是最优决策**——缺"不确定性 + 下一步决策"环节 |
| p2 | 主动学习闭环 | ⭐ 图 2 的闭环：代理模型预测 → 采集函数 → 做实验/模拟 → 数据回流 → 循环。**这就是你们 W7–W9 要做的 pipeline** |
| p3 | 试验设计（DoE）背景 | 传统 DoE 的 A-optimality / G-optimality；普通 DoE 在好坏区域投入相同资源 → 成本指数上升（引出贝叶斯优化） |
| p4 | 贝叶斯全局优化（BGO）| ⭐⭐ 数学核心：f(x) ~ GP(m(x), k(x,x'))；核函数选择（平方指数/指数/Matern）；**超参数通过最小化负对数边缘似然得到**——这就是周一学的 LML！ |
| p5 | 期望改进 E[I] | ⭐⭐ 核心公式：E[I(x)] = (μ−f(x⁺))·Φ(...) + σ·φ(...)；两种极限：σ 小 → 利用（exploit，选 μ 高），σ 大 → 探索（explore，选 σ 大）；探索-利用权衡；多臂老虎机类比 |
| p6 | 其他采集函数 | MOCU（最小化目标代价不确定性）；表 1 汇总各种 utility function |
| p7–9 | 应用 1：铁电材料（实验） | (Ba,Ca,Sr)(Ti,Zr,Sn)O₃ 固溶体：约 60.5 万种组成，只用 **61 个训练点（0.01%）**；SVR + bootstrap 集成估计不确定性；对比 E[I] vs 纯探索 vs 纯利用 vs 随机 |
| p9–10 | 应用 2：LED 光电器件模拟 | 用 GP/随机森林做代理模型替代昂贵的 Poisson–Schrödinger 求解器，150 次迭代后 R²≈0.9 |
| p11–12 | 应用 3：引导 DFT 计算 | 磷灰石 A₁₀(BO₄)₆X₂：96 种组成、13 个训练点、100 个 SVR-RBF 集成；**第 9 次迭代找到最优 Ca₁₀(PO₄)₆F₂**（Eg=5.67 eV） |
| p12 | ⭐ 停止判据讨论 | maxE[I] 不单调下降（最优在 9 轮找到，但 E[I] 到 16 轮才归零）→ **不要一看到 E[I] 变小就停，要确认它持续不回升**。直接关系到你们 W9 的收敛判据（连续两轮提升 <5%） |
| p13–15 | 其他工作回顾 + 展望 | Seko 的 kriging、COMBO 框架；未来方向：多目标性质、多保真度（multifidelity）数据 |

**读的时候重点想（笔记必答）**
1. 用一句话向 A/B/C 解释"什么是主动学习闭环"（周五例会要用！）。
2. E[I] 公式里，μ 和 σ 分别起什么作用？为什么"最好预测 + 最大不确定"的区域最值得采样？

## 📌 两篇之间的桥梁（笔记里建议写一句）
